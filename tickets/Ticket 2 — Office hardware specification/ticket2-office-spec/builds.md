## Build 1 — Accountant

**Load:** Accounting application (assumed 1C or a similar Windows accounting package), spreadsheets, PDF invoices, email and a browser during a normal 8-hour workday. Usually several applications are open together, but there is no 3D or video workload.

**Bottleneck:** Memory and reliability are more important than a discrete GPU. 16 GB is the minimum sensible configuration for the assumed office workload; the Ryzen 5 3400G has integrated graphics, so no graphics card is needed.

**Trade-off:** I chose an older, inexpensive AM4 platform and integrated graphics instead of spending money on a discrete GPU. This leaves budget for a 1 TB SSD, a monitor and a licensed Windows installation. The AM4 platform has a more limited upgrade path than AM5.

## Build 2 — Sales manager

**Load:** CRM in a browser, approximately 25–35 tabs, spreadsheets, email and several video calls each day. Some of these applications will be open at the same time.

**Bottleneck:** Memory is the likely first limit. The i5-12400 has enough CPU performance for CRM and office applications; 16 GB is the budget-conscious starting point, but it may become tight with many browser tabs and video calls.

**Trade-off:** I kept the machine at 16 GB and used the integrated graphics in the i5-12400 instead of buying a graphics card. The saving is directed toward a capable six-core CPU and a Full HD IPS display. This is the build most likely to need a RAM upgrade first.

## Build 3 — Web developer

**Load:** IDE, local development server, browser testing, database, Docker containers and occasional virtual machines. Several memory-heavy tools can run at the same time throughout the workday.

**Bottleneck:** RAM capacity and storage capacity/response time. 32 GB is a better starting point than 16 GB for containers and VMs. The integrated graphics are sufficient for normal web development.

**Trade-off:** I spent more on 32 GB RAM and Windows 11 Pro, but did not buy a discrete GPU. The 4 × 8 GB configuration uses all four DIMM slots, so a future move to 64 GB would require replacing the modules rather than simply adding more.

## Build 4 — Designer

**Load:** Large Photoshop/Illustrator files, multiple design applications, many reference tabs and occasional GPU-accelerated work. Colour consistency matters more than high refresh rate.

**Bottleneck:** GPU performance and memory capacity. A discrete RTX 3050 is an entry-level acceleration option; 32 GB RAM helps with larger projects. The monitor is an IPS model, but it is not a professional factory-calibrated reference display.

**Trade-off:** I chose an entry-level 6 GB RTX 3050 and a better IPS monitor rather than a more expensive GPU. This is a compromise: it is suitable for 2D design and light GPU work, but not ideal for heavy 3D rendering or demanding video effects. A colourimeter and a calibrated wide-gamut monitor would be a future improvement.

## Compatibility and power notes

- The Ryzen 5 3400G and ASUS Prime B550M-K both use AM4. The board uses DDR4 memory.
- The Intel Core i5-12400 and Gigabyte B760M GAMING PLUS WiFi DDR4 both use LGA1700. The motherboard is the DDR4 version, not the DDR5 version.
- The selected 1 TB SSD is SATA 2.5-inch, so it connects by SATA data and power cables; it does not occupy an M.2 slot.
- The DeepCool AG400 listing explicitly supports AM4 and LGA1700.
- The 550 W FSP PSU is sufficient for the low-power integrated-graphics systems and the RTX 3050 system, subject to checking the exact GPU connector and PSU revision before purchase.
- The Huntkey A320G is an mATX case; confirm motherboard dimensions and cooler clearance before ordering.
- PCPartPicker is for compatibility and power checking only. It is not used as a Kazakhstan price source.
